# MDB Instalaciones

Sitio web one-page para MDB Instalaciones, desarrollado con React, Vite y Tailwind CSS.

## Requisitos

- Node.js
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Los datos de contacto y los servicios se pueden editar en `src/data/`.
